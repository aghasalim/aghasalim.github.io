  • ARC Prize 2026, ARC-AGI-2. My own DSL program search scores 0.00 on the hidden set, and the paper track write-up explains why. model-nerf-watch

Is my model quietly getting worse? A daily canary with confidence intervals instead of vibes. Three runs of the same local model land on 90.0% every time, so the noise floor is a 6.4 point interval, not observed drift. That means 60 probes can see a 20 point drop and cannot see a 5 point one, and the README says how many probes you would need. A planted downgrade to a model half the size is caught at p of 1e-08, and the first attempt showed why a token budget change looks exactly like a nerf.

Publications

Retrieval over an Amended Law: Corpus Versioning, Paragraph-Level Citation and Judge Validation for Question Answering on the EU AI Act

Aghasalim Mustafazada and Murad Eyvazov. Draft, 2026. What happens to a legal search tool when the law changes under it. On 11 questions only the amended AI Act can answer, retrieval over the 2024 text finds the right article for 63.6% but the current wording for 0.0%. Paragraph-level chunks raise full recall from 69.7% to 75.8%, and the LLM judge agrees with 41 hand labels on 82.9% of answers. Code and the 123-question set are in the eu-ai-act-rag repository.

Draft, for SSRN Read the PDF

Evaluating a From-Scratch PatchCore on MVTec AD: Metric Protocol, Seed Variance, False-Alarm Intervals and Threshold Calibration

Aghasalim Mustafazada and Murad Eyvazov. Draft, 2026. Five seeds over all 15 MVTec AD categories give image AUROC 0.9873, pixel AUROC 0.9775 and AUPRO 0.9041, within 0.003 of anomalib on the same pipeline. The old 99th-percentile threshold met a 1% false-alarm target in 3 of 15 categories, the calibrated one in 13 of 15. Code is in the explainable-defect-detector repository.

A Multilingual Groundedness Detector that Runs on a Raspberry Pi: Trained Token Classification against LLM Judges and English-only Detectors in 31 Languages

Aghasalim Mustafazada and Teymur Eyvazov. SSRN, 2026. An XLM-RoBERTa token classifier that marks unsupported spans in RAG answers, benchmarked in 31 languages against LLM judges and the English-only detectors. Code, data and the trained weights are in the groundedness repository.

SSRN preprint Read on SSRN DOI 10.2139/ssrn.7497398

Nothing to Verify: Why a Verified DSL Search Scores Zero on ARC-AGI-2

Aghasalim Mustafazada. ARC Prize 2026 paper track, Kaggle, 2026. My program search solves 39 of 1,000 training tasks and 0 of 120 evaluation tasks, and the write-up measures why: on evaluation it never proposes a single candidate, so the verifier has nothing to check. When it does find a program, 3 of 42 fit every example and still fail the test. Code and every number are in the arc-prize-2026 repository.
